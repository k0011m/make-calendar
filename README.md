# MAKEイラストカレンダー

写真やイラストを配置してDay・Week・Monthの予定表を作成するWebアプリです。
バックエンドは使わず、HTML/CSS/JavaScriptだけで動きます。保存先はブラウザの `localStorage` です。

## `.makecal`共有形式

`.makecal`はUTF-8のJSONファイルです。`format`と`version`で形式を識別し、`calendar`にDAY・WEEK・MONTHいずれか1件の内容、`assets`にそのカレンダーで使う自作画像だけを格納します。インポート時はカレンダー・時間枠・自作画像のIDを新しく発行するため、既存データと重複しません。現在の対応バージョンは`1`、ファイル上限は10MBです。

## 制限

UI確認用の静的プロトタイプのため、ログイン、サーバーDB、Cloudinaryは使用しません。
カレンダーと登録画像は端末のブラウザ内に保存され、別の端末やブラウザとは共有されません。PDFは専用変換ではなく、ブラウザの印刷画面にある「PDFに保存」を使用します。
